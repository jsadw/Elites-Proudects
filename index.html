How to get a key

Do these in order. Your key only appears after the last checkpoint.

  1. Open the key page

    Press Get my key. It opens our Panda key system in a new tab.

  2. Finish checkpoint 1

    Press Continue to Next Step, then wait for the checkpoint to load and complete it.

  3. Finish checkpoint 2

    Same again. Do not skip ahead or use a bypasser, the system detects it and rejects the key.

  4. Pass the human check

    Tick the hCaptcha box (I am human), wait for Verification complete, then press Continue.

  5. Copy your key

    Copy the key shown on the final screen and paste it in the box below.

  6. Run the script

    Your key is filled into the script automatically. Copy it and execute it in your executor.

Problems?

    
Quick fixes for the usual issues.

    
The checkpoint page says "This site can't be reached"
Reload the key page and start again. If it keeps happening, the checkpoint link is misconfigured: tell us in Discord so we can fix it.

    
My key says invalid
Copy the key again with no spaces before or after. Keys expire after 7 days, and each key is tied to one device (HWID).

    
I changed PC or reinstalled
Open the key page and use Already have a key? Reset HWID.

    
"Library failed to initialize"
Your executor blocked the request. Try again, check your internet, or switch executors.
